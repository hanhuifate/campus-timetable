# 校园课表

两个校园课表 App 的源码与安装包合集，均为原生 Kotlin 实现、自绘课表界面、无需浏览器：

| 目录 | 学校 | 数据来源 | 安装包 |
| --- | --- | --- | --- |
| `NJFU-Timetable/` | 南京林业大学 | `https://jwxt.njfu.edu.cn`（统一认证 CAS） | `apk/南林课表-v34-debug.apk` |
| `WHIT-Timetable/` | 芜湖职业技术大学 | `https://ehall.whit.edu.cn/publicapp/sys/mykbxt/index.do` | `apk/芜湖课表-v16-debug.apk` |

## 功能

- **登录同步**：内嵌登录页完成统一认证，登录成功后自动抓取并解析本学期课表，支持会话失效后重新登录。
- **本地课表**：课表、元数据存在 App 私有目录，冷启动首帧即绘制完整课表，断网可用。
- **多周浏览**：底部上一周 / 回到本周 / 下一周切换，左右滑动也可翻周；今日课程在顶部卡片汇总。
- **编辑模式**（南林版）：顶部「同步 / 编辑 / 设置」三按钮，未从教务导入课表前编辑按钮不可用（先同步再添加，避免之后导入时重叠）。编辑模式下
  - 点空白格新增自定义课程，长按空白格粘贴复制的课程；
  - 长按自定义课程弹出「编辑 / 复制 / 删除」横向菜单，删除无二次确认；
  - 上下拖拽自定义课程可伸缩起止节次，拖动边界实时夹紧，不与已有课程重叠。
- **冲突提示**：新增/粘贴/拖拽时校验同星期、周次有交集、节次重叠的课程，提示中带出冲突课程的名称、周次与节次。
- **同步保护**：教务数据同步只覆盖教务课程，用户自建的课程不会被冲掉；若自定义课程与导入的教务课程同天、周次有交集且节次重叠，只保留不重叠的节次（重叠周次裁剪、其余周次原样保留，整段被占则删除），并在同步结果里提示。
- **详情弹窗**：圆角卡片展示课程色标、教师、地点、时间与周次。
- **校区作息**（南林版）：设置页可切换白马 / 新庄 / 淮安校区，仅改变节次对应的上课时间显示。
- **上课提醒**：上课前用状态栏通知提醒，默认提前 25 分钟（设置页可改 1-180 分钟）。用 `AlarmManager` 精确闹钟调度，App 未打开、进程被回收也能触发；开机、改时间、覆盖安装后会自动重排。同一天连续的同名课程只在第一段提醒一次。提醒方式可选「仅震动 / 通知音 / 闹钟音 / 铃声」，设置页有「试听当前提醒效果」按钮，按当前选中的方式发一条示例提醒。
  - 震动由 App 直接调用 `Vibrator` 触发，不依赖系统通知分类里的「振动」开关；
  - 选「闹钟音 / 铃声」时通知以横幅弹出，横幅内带「停止」按钮，点停止、按电源键、按音量键都能关；响铃时长只在这两种方式下出现，默认 6 秒。横幅保持系统默认视图，自定义 RemoteViews 会被 HyperOS 归入「更多通知」而不弹。
- **权限引导**：设置页「通知与提醒权限」卡片实时显示通知与精确闹钟的授权状态，一键直达系统里「上课提醒」通知分类（打开「悬浮通知」才弹横幅）、「闹钟与提醒」授权页和「后台运行设置」（自启动 / 省电策略）。
- **导出日历（iPhone 可用）**：设置页可把整学期课表导出为 `.ics`，每个上课时段一条事件、按所选提前量带提醒，iPhone 导入系统日历后由日历负责提醒。

### 网页版（手机 / 电脑浏览器）

`web/` 是零第三方依赖的静态网页 + 本地小后端（Node 18+），适合不想装 App 或在电脑上看课表：

```bash
cd web
node server.js        # 打开 http://127.0.0.1:8787
```

- **登录**：页面右上角「同步」，输入学号密码；由本机的 Node 服务代登录学校统一认证并抓取课表，Cookie 只保存在服务进程内存里，关掉服务即失效。
- **Cookie 兜底**：自动登录被验证码 / 风控挡住时，切到「粘贴 Cookie」——先在浏览器登录 `jwxt.njfu.edu.cn`，从开发者工具复制请求头里的 Cookie 粘进去。
- **功能**：周视图翻周、今日课程卡片（进行中 / 距上课几分钟）、课程详情、校区作息、学期第一周日期、显示周末、导出 `.ics`（可在 iPhone 系统日历里导入并提醒）。
- **缓存与主屏**：课表存在浏览器 localStorage，断网也能看；支持「添加到主屏幕」（PWA manifest + service worker）。
- **手机访问**：电脑上以 `HOST=0.0.0.0 node server.js` 启动（PowerShell 用 `$env:HOST="0.0.0.0"; node server.js`），手机与电脑连同一 Wi-Fi，访问 `http://电脑IP:8787`。
- **周次对不上**：学期起始日默认按「9 月 1 日后的第一个周一」推算，在设置里改「学期第一周周一」即可。

### 在 iPhone 上使用

这个工程是 Android 原生实现，无法直接装到 iOS，但课表可以这样过去用：

1. Android 机设置页 →「导出课表 .ics」，分享到微信 / 邮件 / 文件传输助手；
2. iPhone 上点开该文件，选择「添加到日历」（或先存到「文件」再打开）；
3. 导入后在「日历」里会出现整学期课程，提醒由系统日历触发，App 完全不用常驻后台。

注意两点：课表变动后需要重新导出，并删掉旧的那批日历事件（同一条课程 UID 稳定，但重复导入可能产生重复事件）；`提醒时间` 与「提醒开关」按导出时的设置生成，之后改设置要重新导出。

iOS 上要装原生 App 只能是另一套实现（Flutter / 原生 Swift），且需要 Mac + Xcode 与 Apple 开发者账号（或 7 天续签的侧载），因此当前不提供 iOS 安装包。

### 通知权限说明（HyperOS / MIUI）

- 「允许通知」只是基础开关，「悬浮通知」关掉时提醒会被收进「更多通知」，不弹横幅；
- 「常驻通知」不勾选也能正常提醒；
- 清理后台后提醒是否还能触发，取决于「自启动」和「省电策略」（设为「无限制」最稳），可用设置页的「打开后台运行设置」进入；手动「强行停止」应用时系统会清掉所有闹钟，重新打开应用即可恢复；
- 系统通知分类一旦创建，声音 / 重要级别无法在原渠道上更新，App 每次调整渠道配置都会换新的渠道 ID（当前为 `reminder_alert_v4`），旧渠道自动删除，不需要手动清理。

## 常见问题

- **点「编辑」没反应**：还没从教务导入课表，先去点「同步」。这样先有教务课表、再加自定义课，能避免导入后重叠。
- **同步后自定义课变短或不见了**：同步会保留自定义课程，但和教务课程同天、周次有交集且节次重叠的部分会被裁掉；整段都被教务占用则删除，同步完成的提示里会写明门数。
- **提醒没有横幅 / 收进「更多通知」**：设置页「通知与提醒权限」→「打开通知设置」，确认「允许通知」和「悬浮通知」都打开。
- **提醒没声音**：确认手机没有静音、免打扰未开启；提示音由 App 直接播放，不依赖通知分类里的「声音」选项。

## 构建

环境：JDK 17、Android SDK、Gradle 8.7、AGP 8.5.2、Kotlin 2.0.20。

```bash
# 进入任一子目录后执行
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` 中的 `sdk.dir` 需按本机 SDK 路径自行配置，未纳入版本库。

## 数据与隐私

- 学号、密码、Cookie 只保存在手机本机：密码与 Cookie 由 Android Keystore 的 AES-GCM 密钥加密后写入私有 SharedPreferences，不会上传到任何服务器。
- 网页版的账号密码只发给本机运行的 Node 服务，用于代登录学校 CAS；Cookie 仅存在该进程内存中，服务停止即清除。课表存在浏览器的 localStorage 里，不会同步到任何第三方。
- 仓库中不含任何真实账号、密码或抓取到的课表数据。
- 安装包为 debug 签名，仅用于自用安装与测试。
