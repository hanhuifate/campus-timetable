# 校园课表

两个校园课表 App 的源码与安装包合集，均为原生 Kotlin 实现、自绘课表界面、无需浏览器：

| 目录 | 学校 | 数据来源 | 安装包 |
| --- | --- | --- | --- |
| `NJFU-Timetable/` | 南京林业大学 | `https://jwxt.njfu.edu.cn`（统一认证 CAS） | `apk/南林课表-v28-debug.apk` |
| `WHIT-Timetable/` | 芜湖职业技术大学 | `https://ehall.whit.edu.cn/publicapp/sys/mykbxt/index.do` | `apk/芜湖课表-v10-debug.apk` |

## 功能

- **登录同步**：内嵌登录页完成统一认证，登录成功后自动抓取并解析本学期课表，支持会话失效后重新登录。
- **本地课表**：课表、元数据存在 App 私有目录，冷启动首帧即绘制完整课表，断网可用。
- **多周浏览**：底部上一周 / 回到本周 / 下一周切换，左右滑动也可翻周；今日课程在顶部卡片汇总。
- **编辑模式**（南林版）：顶部「同步 / 编辑 / 设置」三按钮，编辑模式下
  - 点空白格新增自定义课程，长按空白格粘贴复制的课程；
  - 长按自定义课程弹出「编辑 / 复制 / 删除」横向菜单，删除无二次确认；
  - 上下拖拽自定义课程可伸缩起止节次，拖动边界实时夹紧，不与已有课程重叠。
- **冲突提示**：新增/粘贴/拖拽时校验同星期、周次有交集、节次重叠的课程，提示中带出冲突课程的名称、周次与节次。
- **同步保护**：教务数据同步只覆盖教务课程，用户自建的课程不会被冲掉。
- **详情弹窗**：圆角卡片展示课程色标、教师、地点、时间与周次。
- **校区作息**（南林版）：设置页可切换白马 / 新庄 / 淮安校区，仅改变节次对应的上课时间显示。
- **上课提醒**：上课前用状态栏通知提醒，默认提前 25 分钟（设置页可改 1-180 分钟）。用 `AlarmManager` 精确闹钟调度，App 未打开、进程被回收也能触发；开机、改时间、覆盖安装后会自动重排。同一天连续的同名课程只在第一段提醒一次。提醒方式可选「仅震动 / 通知音 / 闹钟音 / 铃声」，设置页有「试听当前提醒效果」按钮，按当前选中的方式发一条示例通知。

## 构建

环境：JDK 17、Android SDK、Gradle 8.7、AGP 8.5.2、Kotlin 2.0.20。

```bash
# 进入任一子目录后执行
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` 中的 `sdk.dir` 需按本机 SDK 路径自行配置，未纳入版本库。

## 数据与隐私

- 学号、密码、Cookie 只保存在手机本机：密码与 Cookie 由 Android Keystore 的 AES-GCM 密钥加密后写入私有 SharedPreferences，不会上传到任何服务器。
- 仓库中不含任何真实账号、密码或抓取到的课表数据。
- 安装包为 debug 签名，仅用于自用安装与测试。
